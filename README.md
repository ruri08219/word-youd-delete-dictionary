One word to erase from the dictionary forever: **gaslighting**.

Deleting "gaslighting" is itself gaslighting: the dictionary denying
the word's existence performs the exact act the word names — telling
the world a real thing never happened. And once it is gone there is
no word left at all for denying someone's reality. The joke is in the
word itself, it lands the moment the word is gone, and no other word
in the field does the thing it names to itself.

## Run it

```sh
python3 main.py
```

Writes `gaslighting` (11 characters, a single word, no trailing newline)
to `/output/entry.txt`. Standard library only.
